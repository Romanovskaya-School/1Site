# Сайт психолога на Vue.js

## Структура

```
psychologist_website/
├── src/
│   ├── views/
│   │   ├── Home.vue      # Главная страница
│   │   └── Admin.vue     # Админ-панель (CMS)
│   ├── App.vue           # Основной сайт
│   └── main.js           # Точка входа
├── index.html
├── package.json
└── vite.config.js
```

## Запуск

```bash
cd psychologist_website
npm run dev
```

## Использование

### Сайт для клиентов
- Открыть `http://localhost:3000/`
- Форма заявки сохраняет данные в браузере

### Админ-панель (CMS)
- Открыть `http://localhost:3000/admin`
- Здесь психолог может:
  - Редактировать всю информацию о себе
  - Добавлять/удалять услуги и цены
  - Просматривать заявки с сайта
  - Экспортировать/импортировать резервную копию

### Резервное копирование
В админ-панели есть кнопки:
- **Скачать резервную копию** — сохраняет все данные в JSON файл
- **Загрузить резервную копию** — восстанавливает данные из файла

## Размещение

```bash
npm run build
# Загрузить папку dist на хостинг
```
